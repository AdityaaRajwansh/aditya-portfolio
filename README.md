- `assets/aditya.jpg` — supplied profile photo

## Publish with GitHub Pages
1. Create a new GitHub repository (for example: `aditya-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL.

The portfolio already contains the GitHub and LinkedIn URLs supplied for Aditya.
